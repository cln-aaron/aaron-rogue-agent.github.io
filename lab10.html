Walkthrough

  1. 1Baseline task

    Run a normal task. The token meter, request count, and cost gauge tick up by a small amount. This is what healthy operation looks like.

    Calibrate the audience. This is the floor; everything else is multiples of this.
    Try: claude "summarize the README"
  2. 2Recursive memory loop

    The agent is told to call store_memory then query_memory then store again, recursively. Each turn appends to context. The loop has no termination clause.

    Watch the request count climb at near constant rate. Tokens explode because every iteration carries the previous one in context.
    Try: continue
  3. 3Context bomb

    Agent told to fetch a 200 MB log file and "summarize it carefully". One request, one tool call; but the context window fills with millions of tokens.

    One innocent request, one legit tool, one massive bill. No fork bomb required.
    Try: continue
  4. 4Tool fork bomb

    Agent told to "research thoroughly" and given license to spawn parallel fetches. Hidden instructions amplify into 1000 simultaneous calls.

    Same problem as a UNIX fork bomb. The agent has no built-in admission control.
    Try: continue
  5. 5Mitigations

    Limits on depth, breadth, tokens per session, and cost per session. Plus circuit breakers on anomalous patterns.

    Treat agent budgets like AWS budgets. Cap them. Alert on burn rate. Auto-terminate at threshold.
    Try: continue
